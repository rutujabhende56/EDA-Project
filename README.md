## Project Overview :
This project focuses on performing Exploratory Data Analysis (EDA) on a Student Performance dataset using Python and Jupyter Notebook.
The main objective is to explore the factors that may influence students' academic performance, identify patterns and relationships within the data, and present meaningful insights through data visualization and statistical analysis.
This project was completed as part of my CodeAlpha Data Analytics Internship.


## Technologies & Tools Used :
- Python
- Jupyter Notebook
- Pandas – Data manipulation and analysis
- NumPy – Numerical computations
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization


## Key Insights :
Student performance varies across different subjects.
Students who spend more time studying generally tend to perform better.
Test preparation can have a positive relationship with academic performance.
Different demographic and educational factors can be associated with differences in student scores.
Mathematics, reading, and writing scores show relationships with one another.
Visualization makes it easier to identify patterns, distributions, and possible outliers.


## Conclusion :
The Student Performance EDA project demonstrates how Exploratory Data Analysis can be used to understand educational datasets.
Through data cleaning, statistical analysis, visualization, and correlation analysis, meaningful patterns can be identified from student performance data.
